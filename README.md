# Sistemes de gestió empresarial: la web
Aquest projecte consisteix en la presentació web de les empreses amb que hem treballat a ERP.
Els autors d'aquesta web som Diego Alessandro Patania Rojas i Marc Silva Domínguez.

En aquest treball hem desenvolupat els nostres coneixements i hem aprés més sobre el disseny web. Aplicant tot el que hem aprés en les classes i aprenent més amb el treball mateix. Amb aquesta pràctica hem aprés sobre estructuració HTML, maquetació CSS i adaptabilitat a diversos dispositius.

Aquesta web conté:
- L'index, la pàgina d'inici.
- Features, on expliquem les funcionalitats principals, aventatges i desaventatges, i una breu comparativa amb la competència.
- Pricing, on s'esmenten les diferents modalitats de pagament.
- Support, on es troba el formulari per contactar-nos i rebre suport online.
